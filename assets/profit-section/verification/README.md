# 구현 검증 기록

검증일: 2026-10-08 (Asia/Seoul)

- `pnpm lint`: 통과, 경고·오류 없음.
- `pnpm exec next build --webpack`: 프로덕션 빌드·TypeScript·정적 페이지 생성 통과.
- 기본 `pnpm build`의 Turbopack은 실행 환경의 로컬 포트 바인딩 제한으로 실패해 Webpack으로 검증했습니다. 프로젝트 빌드 스크립트는 바꾸지 않았습니다.
- 기존 `metadataBase` 미설정 안내는 빌드 시 남아 있습니다. 이번 섹션의 변경 사항이 아닙니다.
- 메인 `/` 페이지에서 1916×1080, 1280×720, 768×1180, 390×844, 320×760 크기를 확인했습니다.
- 데스크톱: 배경·제목·설명·차트·카드·최종 이미지 11개가 정상 로드되고, 실제 초기 순차 등장과 최종 이미지 opacity 1을 확인했습니다.
- 태블릿: 카드 두 열. 390px 모바일: 카드 한 열. 320px: 수치 목록 두 열. 검사한 크기에서 가로 넘침 없음.
- 모바일: 스크롤에 따라 각 카드·안내가 등장하며, 모든 요소의 최종 opacity 1을 확인했습니다. 설명 최소 16px, 안내문 13px.
- 모바일의 수치와 안내는 반투명 한지 바탕을 적용해 배경의 창·나무 그림자 위에서도 읽히도록 했습니다.
- 재진입·화면 크기 변경 후 데스크톱 최종 프레임이 유지됩니다.
- 브라우저 console의 error·warn 목록은 비어 있습니다.
- `noscript` 대체 CSS, 실제 h2, 완성 이미지가 프로덕션 HTML에 포함됐습니다. 모션 감소·인쇄는 전용 CSS로 즉시 노출하도록 구현했습니다.
- 별도 미리보기 route와 재생·일시정지·다시보기 UI를 추가하지 않았습니다.

## 캡처

- `desktop.jpg`: 메인페이지의 완성 섹션 캡처. 1916×821 원본 구도.
- `mobile.jpg`: 390px에서 전체 세로 섹션 캡처. 기존 고정 헤더와 문의 UI가 일부 겹쳐 찍힐 수 있습니다.

브라우저 캡처 API는 JPEG 품질 80·4:2:0 이미지를 반환합니다. 캡처 압축으로 생기는 색상 차이는 최종 자산의 변경이 아닙니다. **표시되는 `final-reference.webp`는 마지막 첨부 PNG와 디코딩 픽셀·알파 차이가 0**인 무손실 파일입니다.

원본 35개의 보관 위치와 SHA-256은 상위 `manifest.json`을 참고하세요. 제공된 사업 수치는 수정하지 않았습니다.
