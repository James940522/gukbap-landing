# 수익 구조 섹션 구현·등장 계획

메인페이지의 기존 `#profit-structure` 섹션을 교체합니다. 별도 미리보기 route나 애니메이션 조작 UI는 만들지 않습니다.

## 데스크톱

- 1200px 이상: 1916×821 원본 좌표계로 배치. 최대 폭 1916px, 비율을 유지하며 축소합니다.
- 섹션이 화면 아래에서 96px 안쪽으로 들어오고, 배경·레이어·최종 이미지가 모두 로드되면 공통 타임라인을 한 번 시작합니다.
- 모든 이동은 12–20px, 확대는 0.97 또는 0.98→1. `tween`과 `[0.22, 0.61, 0.36, 1]` easing으로 천천히 멈춥니다.
- 스크롤 위치에 진행률을 묶거나 화면을 고정하지 않습니다. 재진입해도 다시 재생하지 않습니다.

**3.30초 이후에는 마지막 첨부 이미지의 구도를 그대로 유지합니다.** 분리 자산은 재구성 배경·마스킹 차이가 있어, 마지막 원본을 표시하는 단계가 완성 화면의 일치도를 보장합니다. `final-reference.webp`는 마지막 첨부 PNG와 디코딩 픽셀이 동일한 무손실 WebP이며, Next.js의 추가 손실 압축을 적용하지 않습니다.

## 태블릿·모바일

- 600–1199px: 별도 세로 배경, 중앙 제목과 그래프, 두 열의 카드.
- 599px 이하: 제목 → 설명 → 그래프 → 읽기 쉬운 수치 목록 → 카드 네 개 → 안내문. 카드는 한 열로 배치합니다.
- 첫 문구 0.00초 / 강조 0.20초 / 설명 0.40초로 시작합니다.
- 그래프·카드·안내는 각각 화면 아래 48px 안쪽에 들어올 때 한 번 등장합니다. 화면 밖에서 등장 시간을 소진하지 않습니다.
- 그래프는 0.12초 지연·0.80초 지속, 카드는 0.08초 지연·0.70초 지속, 안내는 0.10초 지연·0.60초 지속.
- 점선은 생략합니다. 부제는 최소 16px, 안내문과 그래프 보조 수치는 13px의 DOM 텍스트입니다.

## 접근성과 대체 표시

- 실제 h2, 설명, 운영 항목 목록, 모든 비율·안내문을 화면낭독기용 DOM으로 제공합니다. 시각용 이미지 중복은 `aria-hidden` 처리합니다.
- `prefers-reduced-motion: reduce`와 인쇄에서는 애니메이션 없이 완성 화면을 표시합니다.
- JavaScript를 사용할 수 없어도 `noscript` CSS로 완성 이미지와 모바일 콘텐츠를 노출합니다.
- 기존 메인페이지 섹션 순서, `#profit-structure` 앵커, 본문 밖의 다른 작업은 유지합니다.
