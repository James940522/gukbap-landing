# 뚝손국밥 수익 구조 섹션 — 분리 이미지

## 구성
- `01_background_pc.png` — 콘텐츠가 없는 PC 배경 (1916×821)
- `01b_background_mobile.png` — 콘텐츠가 없는 모바일 배경 (1080×1920)
- `02_title_line1.png`, `03_title_line2.png`, `04_subtitle.png` — 분리된 상단 텍스트
- `05`–`08` — 개별 설명 카드 4개
- `09_profit_chart.png` — 원본 3D 원형 그래프, 레이블 포함
- `10`–`13` — 점선 연결 장식 4개
- `14_disclaimer.png` — 하단 안내 텍스트
- `asset_positions.json` — 1916×821 원본 좌표계의 각 이미지 위치/크기
- `TtuksonProfitSection.tsx` + `.module.css` — Next.js/Framer Motion 구성 예시

## 사용법

1. PNG 파일만 Next.js 프로젝트의 `public/images/ttukson-profit`에 넣습니다.
2. 컴포넌트와 CSS 모듈을 원하는 UI 폴더로 복사합니다.
3. `npm install framer-motion` (이미 설치되어 있으면 생략)
4. `<TtuksonProfitSection />`을 섹션 위치에 배치합니다.

데스크톱: 원본 기준 좌표로 레이어를 배치하고 순차 등장합니다. 모바일: 배경을 교체하고 상단 텍스트 → 그래프 → 카드 4개 → 안내 문구 순서로 수직 배치합니다. 카드 사이 점선 연결 요소는 모바일에서 숨깁니다. `prefers-reduced-motion` 설정을 존중합니다.

## 유의사항

- **배경 2개는 원본 장면을 참고하여 콘텐츠가 없도록 재구성한 이미지**입니다. 원본 인쇄물과 픽셀 단위로 일치하지 않습니다.
- 투명 레이어는 제공된 원본 그림을 기준으로 추출·마스킹했습니다. 일부 카드 윤곽/미세 그림자는 마스킹 과정에서 약간 달라질 수 있습니다.
- 원본의 도표 비율은 **영업이익 30 + 식재료 37.1 + 인건비 22.2 + 월세 3 + 관리비 2.1 + 기타 3 = 97.4%**입니다. 공개 전 미표기된 2.6%를 설명하거나 수치를 재검증하세요. 또한 영업이익 30%에 대한 실제 산출근거를 확인하세요.
- 헤드라인을 검색엔진과 화면낭독기에서 사용할 수 있도록 컴포넌트에 접근성용 텍스트를 넣었습니다. 운영 시 가능하다면 이미지 대신 실제 DOM 텍스트로 교체하는 편이 좋습니다.
