# 뚝손국밥 수익 구조 섹션 자료

사용자가 제공한 원본 자료를 모두 저장했습니다.

- `source/`: 다운로드 폴더의 PNG 15개와 README, 좌표 JSON, TSX, CSS 원본. 수정하지 않았습니다.
- `source/attachments/image-01.png`–`image-16.png`: 첨부한 순서대로 저장한 이미지 16개. 마지막 파일이 완성 구도입니다.
- `manifest.json`: 원본 경로, 첨부 순서와 분리 자산의 대응, SHA-256, 크기, 알파 채널, 런타임 변환 기록.
- `../../public/images/ttukson-profit/`: 웹용 자산. 텍스트·카드·차트·연결선은 알파를 유지한 무손실 WebP, 배경은 품질 94 WebP입니다. 완성 구도는 원본 PNG와 무손실 WebP를 함께 보존합니다.

## 구도와 마스킹 확인

기준 좌표는 1916 × 821입니다. 제공된 PC/모바일 빈 배경은 마지막 완성 이미지의 배경을 재구성한 것으로, 완성 이미지와 동일하지 않습니다. 제공된 좌표대로 분리 이미지들을 합성하면 전체 이미지의 RGB 평균 절대 차이는 18.54/255입니다. 일부 제목에 배경 조각이 남아 있고 카드의 둥근 모서리가 일부 잘렸습니다.

연결선은 오른쪽 상단에 금색 접점이 없고, 제공 좌표를 그대로 사용하면 오른쪽 연결선이 차트 아래에 가려집니다. 등장 과정에서 사용할 연결선은 마지막 이미지의 접점에 맞춘 SVG 점선으로 구성하는 편이 안정적입니다. 원본 연결선 파일도 그대로 저장했습니다.

PC에서 마지막 첨부 이미지와 동일한 최종 구도를 확보하려면 분리 레이어의 등장 완료 뒤 `final-reference.webp`를 부드럽게 나타내고 완성 프레임으로 유지합니다. 모바일은 별도 세로 배경과 분리 레이어를 사용해 제목 → 차트 → 네 항목 → 안내 문구 순서로 읽기 편하게 배치합니다.

## 원본 수치

차트와 안내 문구의 수치는 사용자 제공 자료에 포함된 내용을 그대로 보존했습니다. 제공된 비율의 합계는 97.4%입니다. 이 자료 보관 작업에서는 값을 수정하거나 새로운 운영 사례·수치를 만들지 않았습니다.
