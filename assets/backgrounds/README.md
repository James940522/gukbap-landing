# 제공받은 섹션 배경

2026-10-01에 전달받은 이미지 9장을 원본의 색감·구도·비율을 유지한 WebP로 변환했습니다.
원본 파일은 전달받은 `guk-asset` 폴더에 그대로 두며, 사이트용 파일은
`public/images/backgrounds/`에 저장합니다. 원본 SHA-256, 파일별 크기와 출력 해상도는
[manifest.json](manifest.json)에 기록했습니다.

## 현재 적용과 우선순위

| --- | --- | --- | --- |

| 005 | `dark-stone.webp` | 뚝손의 기준 | 묵직한 석재 질감으로 육수·재료의 기준 강조 |

기존 한지 풍경 섹션과 브랜드 소개·상권 안내·문의 폼은 현재 배경을 유지해 페이지의 밀도를 조절합니다.
배경만을 위해 새 섹션을 만들지 않습니다. 보관한 006·009는 현재 페이지에서 요청하거나 프리로드하지 않습니다.
새 섹션을 추가할 때 위 추천 용도와 콘텐츠의 여백을 확인하고 배치 설정을 추가하세요.

## 적용 방식

- `src/data/sectionBackgrounds.ts`: 섹션별 이미지, 데스크톱·모바일 강도, 크롭 위치.
- `src/components/ui/SectionBackground.tsx`: Server Component. `next/image`의 반응형 크기와 기본 이미지 최적화 사용.
- 사용하는 섹션에 `section-background-host` 클래스를 지정하고, 내부에 `<SectionBackground name="…" />`를 추가합니다.
- 장식 이미지는 `alt=""`, `aria-hidden`, 클릭 통과 처리. 기존 텍스트·링크·폼과 등장 애니메이션은 별도 레이어에 유지됩니다.
- Hero 배경만 낮은 요청 우선순위로 즉시 로드합니다. 다른 배경은 기본 지연 로딩하며, 배경 때문에 음식 사진을 추가로 프리로드하지 않습니다.
- 밝은 영역은 기존 SVG 질감과 중첩하지 않습니다. 작은 화면에서는 배경 강도를 낮추고 크롭을 별도로 조절합니다.
- 누룽지의 뚝배기 이미지는 **연출 배경**입니다. `nurungjiFeature.image`에 실제 사진이 연결되면 상품 이미지 영역이 다시 나타납니다.
  모바일에서는 뚝배기를 섹션 하단에 배치해 소개 문구의 가독성을 확보합니다.

## 다시 변환하기

```sh
node scripts/optimize-backgrounds.mjs /path/to/guk-asset
```

Next.js가 이미 설치한 Sharp를 재사용합니다. WebP quality 78, effort 6, 최대 너비 1920px,
확대 없음, EXIF 방향 보정, 불필요한 메타데이터 제거. 현재 9장은 원본 해상도 1672px 너비를 유지합니다.
실제 원본 파일을 덮어쓰지 않습니다.
