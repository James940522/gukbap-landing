사진 형식의 참고 이미지이며, 촬영 출처 및 실제 점주·매장 여부는 확인되지 않았습니다.
뚝손국밥의 실제 가맹점, 점주, 교육 현장 또는 창업 사례를 증명하는 자료로 사용하지 않습니다.
실제 브랜드 촬영본이 제공되면 교체합니다.

메인페이지의 ‘성공으로 가는 6단계 로드맵’과 동일한 사진을 사용하지 않습니다.
로드맵에서 사용 중인 `omurice-landing/process-3.png`(체크리스트 검토)와
`omurice-landing/4.png` / `udon-landing/process-6.png`(포장 봉투를 든 직원)는 제외했습니다.

절차는 https://todayudon.com/ 의 가맹절차 6단계를 4개 항목으로 요약했습니다.
상담·상권분석 → 창업 상담, 점포·본사 계약 → 점포·가맹 계약,
교육 → 조리·운영 교육, 오픈·초기 운영 → 오픈·운영 관리로 구성합니다.
최종 진행 순서와 지원 범위는 브랜드 확인 후 확정합니다.
